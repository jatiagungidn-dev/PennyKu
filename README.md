# PennyKu

PennyKu adalah aplikasi pencatatan keuangan personal untuk membantu pengguna
mencatat pemasukan, pengeluaran, wallet, dan budget secara rapi.

## Stack

- React + Vite + TypeScript + Tailwind CSS
- Laravel API
- PostgreSQL di Neon
- Laravel Sanctum

## Struktur

- `apps/api`: Laravel backend
- `apps/web`: React frontend
- `docs`: dokumentasi arsitektur dan keputusan produk
